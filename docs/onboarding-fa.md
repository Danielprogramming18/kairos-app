# معرفی آغازین و آیکون جدید — ۲.۱.۱

ورودی معرفی در public/kairos-intro/kairos-intro.html است. تصویرسازی و انیمیشن‌های تأییدشده حفظ شده‌اند. OnboardingGate در src/components پیام‌های iframe خودش را بررسی می‌کند؛ complete و skip برنامهٔ اصلی را باز می‌کنند. کلید مستقل kairos_onboarding_seen_version با مقدار 1 در localStorage ذخیره می‌شود. دیتابیس، شناسهٔ برنامه و مسیر اطلاعات تغییر نکرده‌اند. اگر بارگذاری معرفی شکست بخورد، پس از ده ثانیه ورود مستقیم بدون ثبت تکمیل ممکن است.

تم ذخیره‌شدهٔ برنامه اولویت دارد؛ در حالت system تم دستگاه دنبال می‌شود. در توسعه، ?intro=1 معرفی را دوباره نمایش می‌دهد. این گزینه در ساخت نهایی اثری ندارد.

آیکون‌های Tauri در src-tauri/icons و آیکون‌های وب در public هستند؛ از همان لوگوی اسلاید اول تولید شده‌اند. ICO واقعی شامل اندازه‌های 16 تا 256 پیکسل است. برای تغییر دوباره، منابع همهٔ اندازه‌ها باید بازتولید شوند.

برای ساخت ویندوز، workflow با نام Build Windows Installer را روی شاخهٔ شامل این تغییرات اجرا کنید. خروجی Setup.exe و MSI در Artifacts قرار می‌گیرد. تغییر فایل‌های منبع، نسخهٔ نصب‌شدهٔ قبلی را خودکار عوض نمی‌کند؛ نصاب جدید لازم است. شناسهٔ com.kairos.workspace حفظ شده است.

اعتبارسنجی: TypeScript و ساخت Vite موفق. تست مرورگر روی خروجی production برای پایان، رد کردن، اجرای مجدد، بسته‌شدن پیش از پایان، حفظ کلید موجود در storage و تم دستی موفق بود. منابع محلی با route مرورگر ارائه شدند؛ این تست ویندوز واقعی نیست. آزمون‌های پروژه با node --import tsx --test اجرا شدند چون اجرای CLI tsx در محیط تست اجازهٔ ساخت pipe نداشت. ساخت نصاب، مهاجرت نصب قبلی و نمایش آیکون در ویندوز باید در GitHub Actions و روی دستگاه واقعی تأیید شوند.
