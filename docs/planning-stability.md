## ۵. دامنه و محدودیت‌ها

- آزمون تعاملی Windows WebView2، اجرای آزمون‌های Rust، نصب روی نسخهٔ قبلی، کامپایل میزبان Java و اجرای APK روی گوشی انجام نشده‌اند. محیط ساخت Rust و Android SDK/JDK آماده نیست و مخزن فقط کد تحویل میزبان اندروید را دارد. آزمایش Chrome با فایل محلی، رفتار گوشی واقعی، کیبورد نرم‌افزاری یا SQLite خود WebView را تأیید نمی‌کند.
- سقف دادهٔ منطقی برنامه‌ریزی ۱۶ میبی‌بایت، هر رکورد ۲۵۶ کیبی‌بایت و پشتیبان وب ۳۲ میبی‌بایت است. پیام کامل پل بومی سقف ۵ میبی‌بایت دارد. بنابراین پشتیبان کامل مجموعه‌ای بزرگ‌تر از حد پل با خطا متوقف می‌شود. خواندن صفحه‌ای دادهٔ برنامه‌ریزی همچنان ممکن است. ادغام پشتیبان دارای برنامه‌ریزی یا چیدمان سفارشی پشتیبانی نمی‌شود. جایگزینی و بازگردانی مسیرهای پشتیبانی‌شده هستند.
- پایگاه فقط اختلاف رکوردها را می‌نویسد. رابط همچنان تصویر وضعیت برنامه‌ریزی را در حافظه می‌سازد. سرعت و حافظه روی گوشی کم‌حافظه اندازه‌گیری نشده‌اند. دقت تخمین روی سابقهٔ واقعی کاربر هم اندازه‌گیری نشده است.

## ۶. ساخت و آزمون بومی بعدی

**ویندوز.** در محیط Windows x64 با Node، Rust stable برای MSVC، ابزارهای ساخت C++ و WebView2، دستورهای زیر را از ریشهٔ همین شاخه اجرا کنید.

```powershell
npm ci
npm run build
cargo test --release --manifest-path src-tauri/Cargo.toml --lib
npm run desktop:build
```

هفت آزمون Rust برای اجرا وجود دارد. بسته‌های ساخته‌شده در `src-tauri/target/release/bundle/nsis` و `msi` قرار می‌گیرند. در حساب آزمایشی، ابتدا ۲.۲.۰ را با یک پروژه، کار، شاخص و چیدمان سفارشی پر کنید و پشتیبان بگیرید. سپس ۲.۲.۱ را روی همان نصب ارتقا دهید. تعداد و شناسه‌ها را با پشتیبان مقایسه کنید، کار ۳۰دقیقه‌ای را تأیید کنید، برنامه را کاملاً ببندید و آفلاین باز کنید. ذخیره، بازیابی، بازگردانی و حفظ چیدمان را در WebView2 کنترل کنید. نصب اولیه روی دستگاه فاقد WebView2 به تأمین Runtime نیاز دارد.

**اندروید.** محتوای `build/android/` را در مسیر assets قبلی پروژهٔ واقعی قرار دهید. اگر میزبان قبلاً پل SQLite داشته است، کلاس به‌روز `KairosAndroidBridge.java` را همراه همان نام پایگاه بگنجانید. شناسهٔ پکیج، کلید امضا و آدرس قبلی `file:///android_asset/…/index.html` باید با نصب مورد آزمون سازگار باشند. میزبان را با Gradle خودش بسازید، APK را روی نسخهٔ آزمایشی قبلی ارتقا دهید و در حالت هواپیما مهاجرت، فرم با کیبورد باز، جابه‌جایی منو، تأیید برنامه، بستن اجباری و بازکردن دوباره و بازیابی فایل را بررسی کنید. اعلان رویدادها در داخل برنامه نمایش داده می‌شود.
- سورس ۲.۲.۱ در شاخهٔ محلی است. نصاب قبلی ۲.۲.۰ متعلق به کامیت مبناست. برای ۲.۲.۱ نصب روی دستگاه کاربر یا انتشار عمومی انجام نشده است.
